COMPLETE TICK LOOP (What Happens Every Simulation Step)
================================================================================

START_TICK:
  │
  ├─► FOR EACH AGENT:
  │   │
  │   ├─► 1. Update Drives
  │   │   └─ agent.drives.tick()
  │   │      Each drive: value += base_rate
  │   │
  │   ├─► 2. Select Most Urgent
  │   │   └─ urgent = agent.drives.most_urgent()
  │   │      Returns highest urgency active drive
  │   │
  │   ├─► 3. Find Behavior Tree (TODO)
  │   │   └─ tree_idx = find_tree_for(urgent.drive_type)
  │   │
  │   ├─► 4. Execute Tree
  │   │   └─ result = tree.execute()
  │   │      Returns Success/Failure/Running
  │   │      ✅ Weights auto-updated
  │   │      ✅ Counters incremented
  │   │
  │   ├─► 5. Execute Action (TODO)
  │   │   └─ action = result_to_action(result)
  │   │      Update world, check success
  │   │
  │   ├─► 6. Apply Feedback (TODO)
  │   │   └─ if success:
  │   │        urgent_drive.partial_satisfy(reward)
  │   │
  │   └─► 7. Check Reproduction (TODO)
  │       └─ if reproduction ready:
  │            offspring = spawn_offspring(parent)
  │
  └─► END_TICK
